## 📖 About

SkillMap AI is an AI-powered learning platform that helps users master any topic through personalized visual learning roadmaps.

Instead of spending time searching for what to learn and where to learn it, users simply enter a topic, and the platform generates a structured learning roadmap, AI-powered notes, curated learning resources, and progress tracking—all within a single platform.

Designed with a modern AI-first experience, SkillMap AI combines intelligent content generation with interactive visual learning to make mastering new skills faster, easier, and more organized.

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/gnaneswar675/SkillMapAi.git
cd SkillMapAi
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env.local` file and add:

```env
DATABASE_URL=
DIRECT_URL=

NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=
CLERK_SECRET_KEY=

GROQ_API_KEY=
```

### Run Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
